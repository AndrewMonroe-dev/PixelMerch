PixelMerch

Case-mosaic signage builder. Type a word, color each letter from real product-photo swatches (or one flat color), and it lays out a build using a fixed pixel font sized to never exceed 6 boxes tall — every case shown upright at its real face dimensions. Everything runs locally in this browser — nothing is uploaded anywhere.

1. Case Palette

Drag case photos here — straight out of PowerPoint or a folder, one or several at once

2. Build Source

3. Case Size

Default is a standard Bota Box: 4⅝" x 10₃⁄₁₆".
Off by default — upright, using the width x height above. When checked, each case shows only its top face as a square (width x width), ignoring the height value.

4. Pixel Resolution

Each letter is rasterized live at this resolution — taller/wider settings pick up more detail, smaller settings get blockier. Total build width still grows with however long the word is.

5. Canvas Size

Adds blank canvas around the generated text so you can freehand-place or remove cases beyond the letters — a border, extra decoration, whatever. Blank cells start as background color; use the Color and Place/Remove edit modes below to build on them.

Letter & Background Colors

Every box in the build is one of these palette colors — there are no blank/empty boxes. Each letter defaults to cycling through your palette in order — change any of them individually above.
